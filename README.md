# De olho no Congresso

Página de inscrição nos alertas semanais sobre o que a Câmara dos Deputados e o Senado Federal vão discutir, com uma tarefa do tamanho do tempo de cada pessoa.

A página é um arquivo só (`index.html`), publicado de graça pelo GitHub Pages. As inscrições vão para o serviço de e-mail (Brevo), que manda os alertas.
